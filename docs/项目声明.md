# 项目声明

## 学习用途

本项目是概率论与数理统计的可视化学习辅助工具。页面中的公式、参数和文字提示用于帮助理解概念，不构成医学、金融、工程、科研或其他专业领域的决策建议，也不能替代教材、教师指导或经过验证的统计软件。

## 数值与模型边界

- 图像由浏览器端数值计算生成，显示结果会受到浮点精度、取样网格和四舍五入影响。
- 极端参数、很大的离散取值范围或很小的概率可能出现显示截断、近似误差或视觉上难以分辨的差异。
- 连续分布的 PDF 是密度而非单点概率；区间概率应通过积分或 CDF 差值理解。
- 多项分布采用三分类示意；多维图是教学型可视化，不代表所有高维情形。
- 页面展示的参数范围是为了保证交互和图像可读性，不等于对应分布的全部理论定义域。

重要计算或正式分析请回到原始公式，并使用经过验证的数值工具复核。

## 数据与网络请求

项目本身不包含账号系统、数据库或表单提交功能，也不会主动保存用户在页面中调节的参数。页面使用 MathJax CDN 渲染公式，因此加载公式时浏览器会向该 CDN 发起资源请求；Plotly 图表库已内嵌在 `index.html` 中。

如果需要完全离线使用，应准备本地 MathJax 资源并相应调整页面引用；这属于部署方式调整，不是当前仓库默认配置。

## 第三方组件

页面使用以下开源组件或其打包内容：

- [Plotly.js](https://plotly.com/javascript/)：交互式二维、三维图表；
- [MathJax](https://www.mathjax.org/)：数学公式渲染，当前通过 CDN 加载。

第三方组件的版权、许可证和使用条件以其官方项目为准。仓库中 `index.html` 内保留了相关打包代码的许可证或来源注释。
