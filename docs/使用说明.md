# 使用说明

## 1. 找到一个分布

页面左侧是分布列表。可以直接滚动浏览，也可以在顶部搜索框输入：

- 中文名称，例如 `正态`、`泊松`；
- 英文名称或缩写，例如 `Normal`、`t`、`F`；
- 图像或主题关键词，例如 `钟形曲线`、`二维`。

分类标题可以展开或收起。点击分布卡片后，右侧会显示该分布的详细内容。

## 2. 阅读一维分布图

右侧图像上方的视图按钮用于切换函数：

- 离散型分布：`概率质量函数 PMF` 与 `分布函数 CDF`；
- 连续型分布：`概率密度函数 PDF` 与 `分布函数 CDF`。

PMF 是各个离散取值对应的概率，PDF 是连续分布的密度曲线，CDF 是从左向右累计的概率。不要把 PDF 曲线在某一点的高度直接当成该点概率；连续分布的概率应通过区间面积理解。

## 3. 调节参数

“参数调节区”会根据当前分布显示可用参数。拖动滑块或修改数值后，图像、公式旁的数值和统计摘要会同步更新。

参数输入会受到分布定义的合法范围约束。例如标准差必须为正，概率参数必须位于 0 和 1 之间，部分离散分布的样本量还必须是整数。输入超出范围时，页面会将其限制到可计算的范围内。

如果想重新开始，点击“恢复默认参数”。切换到其他分布后，每个分布的参数会使用自己的默认值。

## 4. 阅读多维图

二维正态、二维均匀和多项分布提供多维视图。根据分布不同，页面可能显示三维曲面、三维点云、二维热力图或等高图。

- 鼠标拖动：旋转三维视角；
- 滚轮：缩放；
- 悬停：查看局部坐标和函数值；
- 二维图：可使用框选、平移和自动缩放工具。

多项分布页面固定使用三分类示意，以便在二维底面上展示三个类别之间的联合概率结构。它不是对任意类别数的完整可视化替代。

## 5. 切换主题与移动端使用

右上角主题按钮可在浅色和深色模式之间切换。主题会同时影响页面、坐标轴、网格线和多维图背景。窄屏设备上建议竖屏使用，并通过页面滚动查看参数和说明。

## 6. 如何正确使用图像

建议按照“先看定义，再调参数，最后解释图像”的顺序学习：

1. 先确认分布的支持集和参数含义；
2. 调节一个参数，观察位置、宽度、偏度或尾部如何变化；
3. 对照期望、方差和 CDF，解释图像变化的概率意义；
4. 再把当前分布与相近分布进行比较，例如二项与泊松、正态与 t 分布。

图像用于建立直觉，不应单独作为严谨证明或最终统计结论。
