# 概率论与数理统计函数图像库

一个面向学习与复习的交互式概率分布图像库。它把常见分布的公式、参数、图像特征和适用场景放在同一个页面中，适合用来建立“参数变化 → 图像变化 → 概率意义”的直觉。

在线访问：<https://yizhengarcanelec.github.io/probability-statistics-function-gallery/>

## 快速开始

1. 打开在线页面，或直接在浏览器中打开仓库根目录的 `index.html`。
2. 在搜索框输入中文名、英文名、缩写或关键词，例如“正态”“泊松”“二维正态”“t”“F”。
3. 在左侧分类中选择分布，再在右侧查看图像、公式、参数和文字提示。
4. 调节参数，观察图像和统计量说明如何变化；需要回到教材示例时，点击“恢复默认参数”。

完整的交互说明见 [docs/使用说明.md](docs/使用说明.md)，项目边界和第三方依赖说明见 [docs/项目声明.md](docs/项目声明.md)。

## 当前收录

目前共收录 14 个分布函数，分为四类：

| 类别 | 分布 |
| --- | --- |
| 离散型 | 0-1（伯努利）、二项、泊松、几何、超几何 |
| 连续型 | 均匀、指数、正态、卡方、t、F |
| 抽样/联合结构 | 多项（三分类示意） |
| 多维分布 | 二维正态、二维均匀 |

一维离散分布支持 PMF / CDF 切换；一维连续分布支持 PDF / CDF 切换；多维分布提供三维曲面或点云，以及二维热力图/等高图等视图。

## 页面功能

- 按分类展开浏览，并通过关键词快速筛选。
- 用滑块或输入控件调节分布参数。
- 查看公式、支持集、期望、方差、记忆提示和适用场景。
- 在浅色/深色主题间切换。
- 对离散分布使用适度稀疏的横坐标刻度，避免标签重叠。
- 对多维图提供可旋转、缩放和悬停查看的交互图形。

## 本地预览

这是一个静态网页，不需要构建步骤。最简单的方式是直接打开 `index.html`。如果浏览器对本地文件的脚本或 MathJax 加载有限制，可以在仓库目录启动一个静态服务器：

```text
python -m http.server 8000
```

然后访问 <http://localhost:8000/>。页面中的公式渲染使用 MathJax CDN，因此完整公式显示需要网络连接。
